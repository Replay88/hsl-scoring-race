# HSL Major Scoring Race

Points leaders for the Hockey Super League 2017 Major and 2018 Major divisions (2026-27), built from the box scores on hockeysuperleague.ca.

- Site: `docs/index.html` (GitHub Pages)
- Updater: `python3 -I tools/update.py` — runs on a schedule in `.github/workflows/update.yml`, or from the Actions tab ("Run workflow").
